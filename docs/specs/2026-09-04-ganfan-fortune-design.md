# 干饭运势签 · 设计文档

> 日期：2026-09-04 · 状态：已确认
> 项目目的：跑通「AI 开发页游」的完整流程，观察流程中会遇到什么问题、验证零素材（emoji + 代码绘制）下的出片效果。

## 一句话

把「今天吃什么」做成日式抽卡：三张干饭签凭直觉翻一张，翻开一张运势卡——今天吃什么、运势几星、宜什么忌什么，可保存成图片分享。

## 玩法设计

### 核心循环

首页点「抽取今日干饭签」→ 发牌动画摊开三张扣着的签 → 玩家凭直觉翻一张 → 另两张自动亮出（戏剧感）→ 展示完整运势卡 → 保存图片 / 再抽一签。

### 稀有度

| 稀有度 | 概率 | 定位 | 示例 |
|---|---|---|---|
| N | 55% | 日常口粮 | 沙县小吃、兰州拉面、食堂套餐 |
| R | 30% | 小确幸 | 麻辣烫、螺蛳粉、黄焖鸡 |
| SR | 12% | 干饭人高光 | 火锅、烤肉、小龙虾 |
| SSR | 3% | 今日天选 | 和牛自助、海鲜大餐、外婆做的饭（情怀彩蛋） |

- 三张签独立按概率生成；**保底**：若三张全 N，随机一张强制升级为 R+。
- 界面标注各稀有度概率（抽卡仪式感细节）。

### 运势卡字段

食物名 + emoji · 稀有度边框 · 干饭运势 1~5 星（与稀有度正相关，小幅随机浮动）· 宜（如「加蛋、多放辣」）· 忌（如「忌轻食沙拉，你会后悔的」）· 一句按稀有度分层的毒舌/彩虹屁点评。SSR 触发全屏彩虹闪光特效。

### 范围（不做）

每日限额、后端、账号、音效——均留二期。「再抽一签」不限次，按钮文案玩梗（「再抽一签（今日运势 -1）」）。

## 技术设计

- **栈**：pnpm + Vite + React 18 + TypeScript + Tailwind CSS v4 + framer-motion（翻牌/发牌动画）+ html-to-image（存图）+ vitest（单测）。
- **零外部资源**：不引外部字体/图片素材，全部使用系统字体、emoji、CSS/SVG 绘制，保证离线可玩、部署即用。

### 结构

```
src/
├── components/
│   ├── StartScreen.tsx    # 首页：标题 + 抽签按钮 + 概率公示
│   ├── CardTable.tsx      # 三张牌桌面 + 发牌/翻牌动画编排
│   ├── FortuneCard.tsx    # 单张签：背面 / 正面 / 翻转态
│   ├── ResultPanel.tsx    # 运势详情 + 保存图片 / 再抽
│   └── SSRBurst.tsx       # SSR 全屏特效
│   └── StarField.tsx      # 星光背景（CSS 代码绘制）
├── game/
│   ├── data.ts            # 食物库 + 宜/忌/点评文案库（纯数据）
│   ├── rarity.ts          # 稀有度概率 + 抽签生成 + 保底（纯逻辑）
│   ├── fortune.ts         # 运势组装（星级/宜忌/点评）（纯逻辑）
│   └── useDraw.ts         # 抽签状态机 hook：idle → dealing → picking → revealing → result
└── index.css              # Tailwind + 自定义 keyframes
```

`game/` 保持纯函数/纯数据，便于单测与扩内容；组件层只做展示与动画编排。

### 状态机

`idle（首页）→ dealing（发牌动画）→ picking（三选一）→ revealing（翻牌 + 另两张亮出）→ result（运势卡）`，再抽回到 dealing。

### 响应式

移动优先（竖版卡，三张一排）；PC 端居中限宽 ~480px 游戏画幅 + 全屏星光氛围背景（「电脑上玩手游」布局）。

### 测试与验收

- vitest：`rarity.ts` 概率分布与保底、`fortune.ts` 组装逻辑。
- 组件 smoke test；`pnpm build` 通过。
- 浏览器 + 手机视口人工验收，视觉截图记录。
